# Explainer Videos

Short, kid-friendly explainer videos. Watch at https://staktrace-bot.github.io/explainer-videos/

- **What Is a Court?** (`videos/what-is-a-court.mp4`, ~108s) — judge, jury, lawyers, witnesses, fairness, and why we have courts. Captions: `.vtt`; script: `videos/what-is-a-court-script.txt`.
- **How to Read a Clock** (`videos/how-to-read-a-clock.mp4`, ~100s, ages 5-8) — hour and minute hands, o'clock, counting by fives, half past, quarter past/to, and practice. Captions: `.vtt`; script: `videos/how-to-read-a-clock-script.txt`.

Made with Pillow-drawn animation and ffmpeg. Narration: Piper TTS (en_US-amy) for the court video; Kokoro TTS (af_heart voice) for the clock video.
